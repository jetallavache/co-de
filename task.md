## Тестовое задание: Адаптивная верстка главной страницы

### Описание

Необходимо выполнить адаптивную верстку главной страницы согласно предоставленному макету.

[Ссылка на макет в Figma](https://www.figma.com/design/yh7Cudc7f3a6tEn3LQiXnk/%D0%A2%D0%B5%D1%81%D1%82%D0%BE%D0%B2%D0%BE%D0%B5-KONTUR?node-id=22104-10723&t=eyE1achqwXijJuae-0)

### Технические требования

1. Адаптивная верстка главной страницы по макету

2. Баннер-слайдер с использованием Swiper или Slick
 - Отобразить 3 слайда
 - Дополнительные слайды указаны рядом с макетом

3. Информационные блоки ("Обучение в CoDe – это удобно и результативно")
 - Реализовать на Flexbox

4. Модальное окно обратной связи
 - При клике на кнопку "заказать звонок" открывается модальное окно с формой

5. Галерея фотографий
 - Реализовать на Grid
 - При клике фото открывается в полный экран через Fancybox

6. Интерактивная карта
 - Подключить с использованием API (Yandex Maps)

7. Адаптивность
 - Верстка должна корректно отображаться на всех разрешениях от 320px до 1920px

### Технологии

 - HTML5, CSS3, JavaScript
 - Swiper или Slick для слайдера
 - Fancybox для галереи
 - API для карты
 - Flexbox для информационных блоков
 - Grid для галереи
